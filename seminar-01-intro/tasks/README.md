## 1. `Greet`

```go
func Greet(name string) string
```

Вернуть `"Привет, Аня!"`. Для пустого имени — `"Привет, мир!"`.

Разминочная задача: цель — убедиться, что цикл «пишу код → `go test` → читаю
вывод» работает у вас на машине.

## 2. `SumTo`

```go
func SumTo(n int) int
```

Сумма чисел от 1 до `n` включительно, для `n <= 0` — `0`.

**Решать циклом**, не формулой `n*(n+1)/2`. Попробуйте форму `for i := range n`
из Go 1.22 — обратите внимание, что она даёт `0..n-1`.

## 3. `MinMax`

```go
func MinMax(nums []int) (int, int, bool)
```

Минимум, максимум и признак «слайс не пуст». Для пустого и `nil`-слайса —
`0, 0, false`.

Две ловушки, на которых спотыкается большинство:
- начинать поиск максимума с `0` нельзя — сломается на отрицательных числах;
- функция не должна менять входной слайс (отдельный тест это проверяет).

## 4. `CToF` и `RoundToInt`

```go
func CToF(c float64) float64
func RoundToInt(c float64) int
```

Перевод Цельсия в Фаренгейты (`F = C*9/5 + 32`) и округление до целого.

Помните: `9/5` в Go — целочисленное деление, равное `1`. И `math.Round`
возвращает `float64`, а вернуть надо `int` — приведение пишем руками.

Заодно посмотрите в тесте, **как сравнивают числа с плавающей точкой**:
через допуск `eps`, а не через `==`.
