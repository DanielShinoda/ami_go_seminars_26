# Язык программирования Go — материалы семинаров

Учебные материалы курса: конспекты, разбираемые на паре примеры и задачи
с открытыми тестами.

## Быстрый старт

```bash
git clone git@github.com:DanielShinoda/ami_go_seminars_26.git
cd ami_go_seminars_26
go test ./seminar-01-intro/examples/05-first-test
```

Если последняя команда напечатала `ok` — окружение готово.
Если нет — [`docs/setup.md`](docs/setup.md).

## Структура репозитория

```
seminar-NN-тема/
├── README.md      конспект семинара с таймингом
├── examples/      код, который разбирается на паре (запускается go run)
└── tasks/         задачи: solution.go правите вы, solution_test.go — нет
```

## Полезные команды

```bash
go run ./seminar-01-intro/examples/01-hello   # запустить пример
go test ./seminar-02-basics/tasks/...          # тесты задач семинара
go test -v ./путь/к/задаче                     # подробный вывод по подтестам
gofmt -l .                                     # что отформатировано неправильно
gofmt -w .                                     # отформатировать
go vet ./...                                   # статический анализ
```

Есть `Makefile` — `make help` покажет список целей.

## Требования

Go 1.24 или новее (в материалах используется `for i := range n` из Go 1.22
и другие современные возможности). Рекомендуется поставить последнюю
стабильную версию с <https://go.dev/dl/>.

## Для преподавателя

Эталонные решения лежат в `solutions/` и **не попадают в git** (см. `.gitignore`).
Проверка того, что решения проходят открытые тесты студентов:

```bash
make solutions
```

Скрипт собирает во временном каталоге пакет из эталонного решения и открытого
теста, поэтому тест хранится в одном экземпляре и не может разойтись с решением.
